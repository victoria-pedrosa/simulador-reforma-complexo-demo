# Demonstração — Simulação de casos complexos da reforma tributária

> Projeto de portfólio de **Victória Pedrosa**. **Demonstração** de simulação de casos complexos da reforma tributária — versão com dados fictícios (nomes, CNPJs, e-mails e IDs internos substituídos).

## Problema de negócio
Casos complexos da reforma (NFS-e, divergências de item) exigiam estudo individual demorado.

## Antes x depois
| | Antes | Depois |
|---|---|---|
| Como é feito | Análise manual de CSVs de NFS-e e cálculos em planilha. | Simulador lê os CSVs de NFS-e, detecta divergências e monta o estudo para avaliar com o cliente. |

## Ganho
- Estudo complexo padronizado e auditável.

## Tecnologias
Google Apps Script, Google Drive, Google Sheets

## Arquivos
- `Codigo.gs`

## Como usar
Crie um projeto no Google Apps Script, copie os arquivos `.gs`/`.html` e configure as Propriedades do script indicadas no código.
